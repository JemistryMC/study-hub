## كيفية استخدام Patch

قبل تطبيق أي Patch:
1. تأكد من Base SHA الذي بُني عليه.
2. افحص كامل الـ Diff.
3. طبّقه محليًا على نسخة العمل المناسبة.
4. ارفع ملفات المشروع الناتجة إلى `Deploying`، وليس ملف Patch وحده.
5. شغّل CI على Commit الكود الناتج.
